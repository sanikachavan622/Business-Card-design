# Business Card Design - README


**Objective**

The objective of this project was to design a modern and professional business card for personal branding as a Graphic Designer. The design focuses on clean typography, minimal aesthetics, and a balanced visual identity.
_______

**Task Overview**

This business card design includes:

* Front side branding design 
* Back side contact information layout 
* Custom logo integration 
* Modern color palette and wave-inspired visual elements 

The design reflects creativity, professionalism, and simplicity suitable for a designer's personal identity.

______

**Tool Used**

* Adobe Photoshop 

________

**Visual Style**

* Minimal 
* Elegant 
* Professional 
* Modern branding 

________

**Steps Performed**

1. Created initial layout structure 
2. Selected professional color palette 
3. Designed custom logo 
4. Added wave graphics for visual balance 
5. Arranged contact details with icons 
6. Finalized spacing, alignment, and typography 
7. Exported final business card design 

_______

**Outcome**

Successfully designed a clean and visually appealing business card that represents a professional graphic designer identity while maintaining readability and aesthetic balance.
